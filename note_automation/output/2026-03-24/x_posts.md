# X投稿セット：Claude Code × Playwright × NotebookLM。Xブックマークを資産に変えるスキルを作った

生成日：2026-04-17（2026-04-18 修正）

---

## ① X長文記事（そのままXに貼る）

X長文記事を取得したら、1件で35,803文字入ってきた。

140文字のツイートと同じアカウントに、3万字超えの記事が存在している。
それが全部NotebookLMの知識ベースに入る。

▼ 作ったもの

スラッシュコマンド1発でXブックマークをNotebookLMに同期するClaude Codeスキル。

/x-bookmark-to-notebooklm

このコマンドだけで、ブックマーク取得からGoogle Driveへのアップロードまで全部動く。
通常ツイート・X長文記事・引用ツイート・外部リンクの本文（最大5000文字）まで全対応。

▼ 7日間のデバッグ地獄

完成形だけ見るとシンプルだけど、開発中はバグの連続だった。

・長文が途中で切れる → 2フェーズ構造に変更
・ファイルが空で保存される → 非同期描画の待機を追加
・6番目のツイートが別人のになる → DOMの仮想化が原因、ゆっくりスクロールに変更
・削除済みと思ったらX記事形式 → セレクタが全く違う
・成功率50% → アクセス間隔を2秒に設定

全部Claude Codeとの会話で解決した。コードの知識はゼロのまま。

▼ 「コードは正しいのに動いていない」が一番難しい

全27ファイルを調べたら引用ツイートが1件も記録されていない。
コードを読む限りでは、取得は実装されている。

原因は保存フォーマットの問題だった。
取得はできていたけど、保存時のマーカーの書き方が想定と違っていて検索で見つからなかった。

「コードを読む」と「実データを検証する」は別の作業。

▼ ブックマークする行動が変わった

「なんとなく保存する」から「これをNotebookLMに入れる価値があるか」を考えてからブックマークするようになった。

溜めるだけだったものが、自分の知識ベースとして機能するようになると、意味が変わる。

詳しくはリプライ欄👇
