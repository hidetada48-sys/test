# 記事テーマ

systemdでXブックマーク週次収集を完全自動化した話。

## テーマの核心

Claude Code の x-bookmark-weekly スキルと systemd タイマーを使って、
X（Twitter）のブックマークを毎週自動収集・md化・GDriveアップロードまで全自動化した記録。

実装から5日間「一度も動いていなかった」という失敗があり、
原因は2つ：
1. systemd はログインシェルの環境変数を引き継がない（→ 401認証エラー）
2. スキルファイルが ~/.claude/skills/ に未登録だった

この2つを解決して完全自動化を達成するまでの試行錯誤の記録。

## 読者ターゲット

- Claude Code を使っている人
- systemd でタスク自動化をしたい人
- 「動かない → 原因究明 → 解決」の実録に興味がある人

## 記事の方向性

「完成図」より「詰まりポイントとその解決」を軸にする。
v1の手動運用 → v2の設計 → 「動いていない」発覚 → 原因究明 → 解決 という
リアルな試行錯誤の記録として書く。
