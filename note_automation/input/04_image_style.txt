# 画像スタイル・トンマナ指定ファイル
# このファイルを編集して、生成する画像の雰囲気を指定してください。
# #で始まる行はコメントとして無視されます。

## 全体のトンマナ
# 例：明るい・温かみのある・プロフェッショナル・ナチュラル など
明るく親しみやすい雰囲気。読者が「自分にもできそう」と感じられるスタイル。

## 色味・カラーパレット
# 例：白・ベージュ・青系 など
白背景をベースに、青・グリーン系のアクセントカラー。清潔感のある配色。

## 被写体・モチーフの方向性
# 例：人物あり・手元のアップ・パソコン・自然など
パソコンや手元など作業シーンを中心に。日本人モデル歓迎。人物ありでも可。

## 画風・質感
# 例：写真調・イラスト調・フラットデザイン など
写真調・リアル寄り。テキストや文字は一切含めないこと。

## 避けたいもの
暗い・重い・ネガティブな印象の画像。過度に加工されたもの。英語テキストが入ったもの。
