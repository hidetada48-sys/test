# 記事テーマ

Claude Codeの「記憶」をPC間で共有する仕組みを自作した話。

## テーマの核心

Claude Codeはセッションをまたいで記憶しない。
さらに複数PC（Linux / Windows）を使うと、記憶が完全にバラバラになる。
この問題を解決するために、basic-memory × Google Drive による PC 間記憶共有システムを段階的に構築した記録。

## 読者ターゲット

- Claude Code を使っている人
- 複数PCやデバイスで Claude を使いたい人
- AIに「前回の続き」から始めてほしいと思っている人

## 記事の方向性

「完成図」より「試行錯誤の経緯」を軸にする。
トラブル → 原因究明 → 設計変更 という繰り返しのリアルな記録として書く。
